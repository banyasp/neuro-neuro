# Hardware spec: `scnn`

Generated by `ML/export.py` from `ML/common.py` and `ML/scnn.py`. Do not edit by hand.

Treat sizes and constants as Verilog **parameters** (they may be tuned).
The **math rules** must match exactly; ML will tell you before changing them.

## Inputs (shared by every model)

| Name | Value | Notes |
|---|---|---|
| `N_IN` | 46 | 23 EEG channels x 2 (UP, DOWN) |
| `T` | 128 | timesteps per window (1 s at 128 Hz) |
| `WINDOW_STEP` | 64 | new window every 64 samples (0.5 s) |
| Weight type | signed int8 | |
| Membrane type | signed int16, saturating | [-32768, 32767] |

Input line order: line `2*ch` = UP spike of channel `ch`, line `2*ch + 1` = DOWN spike.

## Model C: spiking convolutional NN (SCNN)

46 inputs -> layer 1 temporal (23 x 8 = 184 LIF) -> layer 2 depthwise spatial (8 x 2 = 16 LIF) -> layer 3 output (2 LIF). 656 int8 weights, 202 int16 membranes.

| Name | Value | Notes |
|---|---|---|
| `N_CH` | 23 | EEG channels; channel `ch` owns input lines `2*ch` (UP) and `2*ch + 1` (DOWN) |
| `K` | 16 | taps per temporal filter |
| `C` | 8 | temporal filters (layer-1 neurons per channel) |
| `D` | 2 | spatial units per filter (layer 2) |
| Readout | depthwise | |
| `K_LEAK` (leak shift) | 5 | every layer |
| `THETA` | 64 | every layer |
| Bias | none | |

Filter groups (tap `k` of filter `f` reads the input frame from `k * d_f` steps ago; tap 0 = now):

| Filters | Dilation `d` | Frames read | Span |
|---|---|---|---|
| 0-3 | 1 | t, t-1, ..., t-15 | 125 ms |
| 4-7 | 3 | t, t-3, ..., t-45 | 359 ms |

**Spike history:** layer 1 needs the last **46 input frames** (current one included), i.e. a
46-deep x 46-bit shift register. Frames before the window start are all-zero
(clear the history at the start of every window, like the membranes).

Time scale: one timestep = one EEG sample at 128 Hz (7.81 ms).

### Math, per timestep

Every neuron is Model A's LIF neuron, unchanged: **leak** `v = v - (v >>> K_LEAK)`, **integrate** its active
inputs in the order below with `v = sat16(v + w)` after **every** add, **fire** `s = (v >= THETA)`,
**reset** `v = v - THETA` where `s == 1`. Each layer uses the previous layer's spikes **from the same
timestep** (layer 1, then layer 2, then layer 3, within one step).

**Layer 1 (temporal, convolution as delayed synapses)**, neuron `(ch, f)`, filter `f` in a group with
dilation `d`: its 32 inputs are `x[2k + p] = s_in[t - k*d][2*ch + p]` for tap `k = 0..15` and polarity
`p` (0 = UP, 1 = DOWN). For each `i = 2k + p` with `x[i] == 1`, in **increasing `i`** (tap ascending, UP
before DOWN): `v = sat16(v + W1[2k + p][f])`.

**Layer 2 (depthwise spatial)**, unit `u = f*2 + j` (filter `f`, unit `j < 2`): its inputs are
the 23 layer-1 neurons of filter `f` only. For each `ch` with `s1[ch][f] == 1`, in **increasing `ch`**:
`v = sat16(v + W2[ch][u])`.

**Layer 3 (output)**, neuron `o`: inputs are the 16 layer-2 units. For each `u` with `s2[u] == 1`, in
**increasing `u`**: `v = sat16(v + W3[u][o])`.

- All membranes and the spike history reset to 0 at the start of every window.
- **Decision:** seizure (1) if output neuron 1 spiked **more** times than neuron 0. Tie = 0.
- Layer-1 neuron `(ch, f)` is index `n = ch*8 + f` in every trace.

### Cost

Worst case **3344 adds per step**, assuming at most one of UP / DOWN fires per
channel per step (true for the delta encoder; the random test vectors break this, so don't rely on it).
Layer 1 accounts for 2944 of them (23 channels x 8 filters x 16 taps).

## File format (`.mem`, for `$readmemh`)

- Hex, no `0x` prefix. First line of every file is a `//` comment describing it.
- **Signed values** (weights, membranes): two's complement, fixed width. int8 = 2 hex digits
  (`-1` = `ff`), int16 = 4 hex digits (`-1` = `ffff`). Sign-extend when you load them.
- **Spike rasters** (`input_spikes`, `expected_spk_*`, `expected_out`): one word per timestep
  (address = `t`), all lines packed into the word, **bit `i` = line/neuron `i`** (LSB = 0).
  E.g. `reg [N_IN-1:0] spikes [0:T-1]; $readmemh("input_spikes.mem", spikes);`
- **Multi-value traces** (`expected_mem_*`): one value per word, address = `t*N + j`.

| File | Contents |
|---|---|
| `weights_<name>.mem` | int8, one per word, row-major (layouts above) |
| `input_spikes.mem` | T words of N_IN bits |
| `expected_spk_<layer>.mem` | T words, one bit per neuron |
| `expected_mem_<layer>.mem` | T*N words, int16 |
| `expected_out.mem` | T words, one bit per output neuron |
| `expected_counts.mem` | one unsigned 16-bit word per output neuron: spikes over the window |
| `expected_decision.mem` | one word: 1 = seizure, 0 = no seizure |

`reference_scnn.py` (top folder only) is the standalone integer reference (NumPy only).
`python reference_scnn.py` re-checks every case.
