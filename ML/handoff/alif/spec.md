# Hardware spec: `alif`

Generated by `ML/export.py` from `ML/common.py` and `ML/alif.py`. Do not edit by hand.

Treat sizes and constants as Verilog **parameters** (they may be tuned).
The **math rules** must match exactly; ML will tell you before changing them.

## Inputs (shared by every model)

| Name | Value | Notes |
|---|---|---|
| `N_IN` | 46 | 23 EEG channels x 2 (UP, DOWN) |
| `T` | 128 | timesteps per window (1 s at 128 Hz) |
| `WINDOW_STEP` | 64 | new window every 64 samples (0.5 s) |
| Weight type | signed int8 | |
| Membrane type | signed int16, saturating | [-32768, 32767] |

Input line order: line `2*ch` = UP spike of channel `ch`, line `2*ch + 1` = DOWN spike.

## Model B: ALIF SNN 46 -> 64 -> 2

Same inputs, sizes, output layer and decision rule as Model A (`lif`). The hidden layer adds
one adaptation register `a` per neuron that raises its threshold after every spike.

| Name | Value | Notes |
|---|---|---|
| `N_HIDDEN` | 64 | adaptive (ALIF) neurons |
| `N_OUT` | 2 | plain LIF. Neuron 0 = non-seizure, neuron 1 = seizure |
| `K` (leak shift) | 5 | membrane leak, both layers |
| `THETA` | 64 | base threshold, same for both layers |
| `K_A` (adaptation shift) | 7 | hidden layer only |
| `A_INC` (adaptation step) | 16 | hidden layer only |
| Bias | none | |

Time scale: one timestep = one EEG sample at 128 Hz, so a 128-step window is
1 s, with a new window every 0.5 s. The membrane leak
`K = 5` gives decay `1 - 2^-5` per step, a time constant of about
31.5 steps = 0.25 s. The adaptation leak
`K_A = 7` gives a time constant of about 127.5 steps = 1.00 s.

Input spikes come from per-channel delta modulation in Python: each channel is divided by a
fixed per-channel scale, then thresholded at `alpha = 0.3` (so each channel has its
own threshold `d_c = alpha * scale_c`). None of this is visible to hardware, which just reads
the spike raster.

### Math, per timestep

**Layer 1 (ALIF)**, membrane `v` (int16), adaptation `a` (int16, never negative), input spikes
`s_in` (0/1), weights `W1` (int8, `[n_in][n_out]`):

1. **Leak:** `v = v - (v >>> K)` (arithmetic shift).
2. **Adaptation leak:** `a = a - (a >>> K_A)`.
3. **Integrate + saturate:** for each input `i` with `s_in[i] == 1`, in **increasing `i`**:
   `v = sat16(v + W1[i][:])`. Saturate after **every** add, not once at the end.
4. **Fire:** `s_out = (v >= THETA + a)` (signed compare, using `a` from step 2).
5. **Reset:** where `s_out == 1`, `v = v - THETA` (the **base** threshold, not `THETA + a`).
6. **Adapt:** where `s_out == 1`, `a = a + A_INC`.

**Layer 2 (LIF)**, exactly Model A's math: steps 1, 3, 4, 5 with `a = 0` (no adaptation register).

- Layer 2 uses layer 1's spikes **from the same timestep**.
- All membranes **and adaptation registers** reset to 0 at the start of every window.
- **Decision:** seizure (1) if neuron 1 spiked **more** times than neuron 0 over the window. Tie = 0.

Notes:
- The arithmetic shift rounds toward -inf: a negative `v` leaks all the way to 0, but a
  positive `v` in 1..31 has `v >>> K == 0` and does **not** leak. Likewise `a` in
  1..127 does not leak.
- `a` is always in `[0, 2175]` (`(A_INC + 1) * 2^K_A - 1`), so `a` and `THETA + a` (at most
  2239) fit in int16 and need **no** saturation logic.
- The reset only runs when `v >= THETA + a >= THETA > 0`, so it can't underflow. Only step 3
  needs saturation logic.
- Order of adds matters only when saturation happens (see the `saturation/` case).

## File format (`.mem`, for `$readmemh`)

- Hex, no `0x` prefix. First line of every file is a `//` comment describing it.
- **Signed values** (weights, membranes): two's complement, fixed width. int8 = 2 hex digits
  (`-1` = `ff`), int16 = 4 hex digits (`-1` = `ffff`). Sign-extend when you load them.
- **Spike rasters** (`input_spikes`, `expected_spk_*`, `expected_out`): one word per timestep
  (address = `t`), all lines packed into the word, **bit `i` = line/neuron `i`** (LSB = 0).
  E.g. `reg [N_IN-1:0] spikes [0:T-1]; $readmemh("input_spikes.mem", spikes);`
- **Multi-value traces** (`expected_mem_*`): one value per word, address = `t*N + j`.

| File | Contents |
|---|---|
| `weights_<name>.mem` | int8, one per word, row-major (layouts above) |
| `input_spikes.mem` | T words of N_IN bits |
| `expected_spk_<layer>.mem` | T words, one bit per neuron |
| `expected_mem_<layer>.mem` | T*N words, int16 |
| `expected_out.mem` | T words, one bit per output neuron |
| `expected_counts.mem` | one unsigned 16-bit word per output neuron: spikes over the window |
| `expected_decision.mem` | one word: 1 = seizure, 0 = no seizure |

`reference_alif.py` (top folder only) is the standalone integer reference (NumPy only).
`python reference_alif.py` re-checks every case.
